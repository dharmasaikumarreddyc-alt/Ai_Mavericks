Customer Intent
Voice or Text
User speaks or types a shopping goal ("get me a vegan breakfast under $15"). Web Speech API captures voice; the UI ships the text to the assistant agent.
Assistant Agent
Intent Parser & Router
/api/agents/assistant — classifies intent (shop, reorder, check status), extracts constraints (budget, category, dietary), and hands off to the right specialist agent.
Discovery Agent
Cross-merchant search
/api/agents/discover — LLM-reasoned merchant matching over local merchants + bundled DummyJSON catalog. Ranks by relevance, distance, offers.
Inventory Agent
Product finder
/api/agents/inventory — LLM chooses specific SKUs from a merchant catalog to fulfil the intent. Falls back to keyword search when the LLM is unavailable.
Smart Cart Agent
List → cart
/api/agents/smart-cart — parses a shopping list ("milk, eggs, bread") into structured cart items with quantities and preferred merchants.
Budget Shop Agent
Cap-aware allocator
/api/agents/budget-shop — allocates a fixed budget across categories, maximising coverage while staying under the cap.
Predict Order Agent
Reorder forecasting
/api/agents/predict-order — reads order history and predicts what to reorder next, when, and in what quantity. Powers "same as last week".
Rules Agent
Guardrails & approvals
Enforces per-user spending caps, blocked categories, dietary rules, approval thresholds. Blocks or escalates before payment.
Comparison Agent
Price optimisation
Compares equivalent SKUs across merchants and picks the best price factoring in discounts, delivery, and merchant rating.
Narration Agent
SSE thinking stream
/api/agents/narrate — streams the agent's "thinking out loud" as SSE tokens so the UI shows live progress instead of a spinner.
Payment Agent
Virtual card selector
/api/agents/payment — picks the right saved card / virtual card, applies vendor caps, and prepares the payment intent for checkout.
Checkout Agent
Order finaliser
Backend AutoGen agent that finalises the order, writes it to the DB, and returns a receipt payload. Blocks on approval when rules require it.
Receipt Agent
Summariser
/api/agents/receipt — turns a raw order into a friendly, LLM-written receipt summary shown to the user post-checkout.

End-to-End Workflow

🎙️ Intent Capture: User speaks or types a shopping goal; Web Speech API + UI ship it to the assistant.
🧠 Assistant Routing: LLM classifies intent and hands off to the right specialist agent (discovery, smart cart, budget, reorder).
🛍️ Discovery & Inventory: Cross-merchant search picks the best merchants and specific SKUs to fulfil the request.
📊 Comparison & Prediction: Prices, offers, and reorder history reshape the cart for value and habit.
🛡️ Rules & Approvals: Spending caps, blocked categories, and approval thresholds gate the order before payment.
💳 Payment & Checkout: Payment agent picks the right card; checkout agent finalises the order in the backend.
🧾 Receipt & Narration: Receipt agent summarises the order; narration stream keeps the user informed throughout.
📬 Delivery & Dashboard: Order is tracked in the account dashboard; notifications fire on state changes.
🤖 Agent Orchestrator: AutoGen coordinates every agent, enforces sequencing, and streams live status to the UI.
